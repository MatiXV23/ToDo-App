# ToDoApp

Tablero de tareas estilo Scrum/Kanban, liviano y en tiempo real: proyectos, epics, tareas y subtareas, sprints opcionales, integración con GitHub, automatizaciones y sugerencias con IA.

> README completo (instalación, variables de entorno, Google OAuth y GitHub App) en camino.

```bash
npm install
npm run db:up
npm run db:migrate
npm run dev
```
